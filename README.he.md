# תבנית לאפליקציות אנדרואיד

אפליקציה חדשה בלי מחשב ובלי Android Studio: Claude כותב את הקוד, GitHub בונה את ה-APK, ומתקינים מלינק קבוע.

## אפליקציה חדשה
1. בעמוד הריפו הזה: **Use this template** ← **Create a new repository** (פרטי). נותנים שם, למשל `steps-counter`.
2. בריפו החדש: **Settings ← Secrets and variables ← Actions ← New repository secret**
   - שם: `DEBUG_KEYSTORE_B64`
   - ערך: אותו ערך כמו במפות עמדה (מפתח החתימה המשותף שלך).
3. בשיחה עם Claude: נותנים לו את הלינק לריפו החדש ומתארים מה האפליקציה עושה. הוא מריץ
   `tools/new-app.sh` (שם, מזהה, שם קובץ), בונה את המסך הראשון ודוחף.
4. אחרי כמה דקות ה-APK מוכן:
   `https://github.com/<owner>/<repo>/releases/download/latest/<שם>.apk`

## מה יש בתבנית
- **בנייה בענן** (`.github/workflows/build.yml`): בדיקות, בנייה, בדיקת חתימה, ושחרור `latest` בכל דחיפה ל-main.
- **מספר גרסה** = מספר ה-commits, כך שכל גרסה מתקינה את עצמה מעל הקודמת.
- **מסך ראשון בעברית** עם מספר גרסה וכפתור "שיתוף יומן תקלות" (כולל דוח קריסה מהפעם הקודמת).
- **תיקיית `core`** ללוגיקה בלי אנדרואיד, עם בדיקות שרצות בענן (`core-tests`).
- **`CLAUDE.md`**: הכללים ש-Claude עובד לפיהם.
